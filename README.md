# Bolt’s World Tour

[Follow Bolt around Earth](https://thatorjohn.github.io/gh-profile/). He picks new destinations as he goes, with a fresh trip for each visitor.

The static site lives in `docs/` and publishes from `main` through GitHub Pages. To preview locally, run `python3 -m http.server 8000 --directory docs` and open `http://localhost:8000`.
